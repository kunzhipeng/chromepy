# 2026-11-06

## chromepy: random_move() 拟人化改造（chrome.py）

把 `Chrome.random_move()` 从「一次 mouseMoved 瞬移 + `random.randint` 到窗口外框尺寸」重写为轨迹级拟人移动，并新增 `move_to()`。

实现要点（均在 `Chrome` 类「拟人化鼠标移动」区块）：
- `_viewport_size()`：改用 `window.innerWidth/innerHeight` 取视口尺寸。**旧代码用 `get_window_info()['bounds']` 是 bug**，那含地址栏/标签栏，落在其上的坐标不产生页面内鼠标事件。
- `_min_jerk()` + `_fitts_duration()`：钟形速度剖面（带 skew 使加速段短于减速段），耗时按 Fitts 定律 `0.085+0.13*log2(1+d/24)` 随距离对数增长。
- `_plan_move()`：三次贝塞尔（控制点沿法向随机偏移 → 自然弧线）+ 低频正弦与高斯手抖（终点前收敛）+ 偶发中途卡顿，每步 delay 归一化保证总耗时稳定。
- `_emit_move()`：按 `_MOUSE_HZ=85` 逐点派发 `mouseMoved`，带 `timestamp=time.time()`、`button='none'`、`buttons=0`；坐标取整并跳过位置未变的点。
- `move_to()`：维护 `self._mouse_pos` 作为起点（在 `__init__` 初始化、`click_xy()` 同步）；长距离时 55% 概率先冲过目标 0.4%~3% 再短促修正；到位后 35% 概率做 1~2 次至少 1px 的微调。
- `random_move(times, interval, timeout, area=None)`：签名向后兼容；45% 概率就近活动（±80~320px），间隔时间随机浮动 0.6~1.6 倍，默认四边各留 4% 边距。

验证：在 esus7 真实 chrome（headless，视口 800x600）抓 `mousemove` 事件核对——单次 320px 移动 47 个事件/0.82s、最大单步 14.9px、速度剖面 [61,605,834,347,85] px/s 呈钟形、全部落在视口内、`click()` 正常。README 增补「模拟鼠标移动（拟人化）」小节。
